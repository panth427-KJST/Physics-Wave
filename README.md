# ฟิสิกส์ของคลื่น ม.5 — ภาคเรียนที่ 2 ปีการศึกษา 2569

| โฟลเดอร์ | บท | สถานะ |
|---|---|---|
| `ch09-waves/` | บทที่ 9 คลื่น | 9.1–9.2 พร้อมใช้ |
| `ch10-wave-optics/` | บทที่ 10 แสงเชิงคลื่น | กำลังจัดทำ |
| `ch11-ray-optics/` | บทที่ 11 แสงเชิงรังสี | กำลังจัดทำ |

- แต่ละบทเปิดที่ `<โฟลเดอร์>/index.html` (ไฟล์เดียวจบ ใช้ออฟไลน์ได้)

- `tools/make_placeholders.py` สร้างหน้า "กำลังจัดทำ" (ไม่เขียนทับบทที่มีไฟล์จริงแล้ว)
